# Prism UI implementation plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution.

**Goal:** Deliver a readable, navigable native sidebar and inspector with
per-agent Markdown notes, based on the user's interaction contract.

**Architecture:** Keep providers, collector schedules and data models intact.
Separate layout, semantic color, content summaries, help/actions and the Notes
editor from the entrypoint coordinator. Start with an executable terminal
gallery so the user can iterate on concrete screens.

**Tech Stack:** TypeScript, Node >=22.13, existing terminal primitives.

**Spec:** `docs/superpowers/specs/2026-10-06-prism-ui-design.md`

## Global constraints

- Preserve all reference cursors, reader anchors and selected-open collection.
- Every selectable entry has `?` help; Enter navigation carries a right arrow.
- Full meaningful summaries fit; full content opens as wrapped details.
- No new runtime dependencies or Windows-specific fixes.
- Keep missing native indices/remote visibility APIs as upstream dependencies.

## Review focus

- Tiny/short terminal: selection, essential values and navigation stay visible.
- Long Unicode names/paths: meaningful summaries fit and full facts are retained.
- External Notes edit: a stale draft must not overwrite newer content.
- Session focus change during editing: the draft stays on its original agent.
- User-edited native preset: migration preserves modifications and backups.
